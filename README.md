# Замовлення з «Корчми Родина»

Telegram Mini App для спільного замовлення з ресторану «Корчма Родина» (Барселона).
Одна статична сторінка `index.html`: повне меню (119 позицій, 5 груп), вибір кількості,
надсилання замовлення в чат і вкладка підсумку для організатора.

Сторінка: https://yaroslav-landdeal.github.io/rodyna-order/

Оновлення цін або страв — правка масиву `MENU` в `index.html` і коміт у `main`.
